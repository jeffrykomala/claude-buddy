### 1.1 Platform layer (§9.0)

### 1.2 Physics (pure, test first; §6.2-6.5)

  - [x] wall cling or bounce, seeded RNG for test determinism
  - [x] engine tests from §16 (minus the ledge cases)
- [x] `physics/behavior.rs`: weighted behaviors loaded from `behaviors.json`
      (floor, wall and ceiling sets)
- [x] `physics/drag.rs`
  - [x] grab and follow the cursor
  - [x] release detection by polling
  - [x] throw velocity = average over the last 100 ms, capped at 1500
  - [x] click vs. drag (4 pt / 250 ms)
  - [x] right click (`is_right_click`; menu itself is Phase 3)

### 1.3 Pet window
- [x] `pet_window.rs`: 60 Hz tick, world refresh every 250 ms (main-thread
      `NSScreen` read), `step`, `set_position(LogicalPosition)`, emits `pose`
- [x] Commands `grab` and `click`
- [x] Handle display changes: respawn at top-center of the main display when
      off every display

### 1.4 Sprites (§9.2)
- [x] `src/sprite.ts` (+ `character.ts` for parsing/pose/frame logic,
      `placeholder.ts` for the fallback shape)
  - [x] Format A (sheet) and Format B (Shimeji folder) loaders
  - [x] pose fallback: alias → `think` → `stand`
  - [x] mirror when facing right, `devicePixelRatio`, pixelated rendering
  - [x] built-in placeholder shape
  - [x] `pet://pose` event now carries `{ pose, facing }` so the sprite can mirror
- [x] `vitest`: character parsing, aliases, fallbacks (71 tests, ~99% coverage)
- [x] **Shiba task:** no free Shiba art exists, so the Shiba is generated in
      code (`scripts/generate-shiba.mjs`, `npm run art:shiba`) into
      `public/characters/shiba/` (21 poses, 32×32 frames at ×4). License is
      recorded in `character.json`; `src/shiba.test.ts` checks it. Poses it
      lacks (listen, ask, catch, read, write, browse) alias to drawn ones.
      *Needs a visual check in `npm run tauri dev`.*
- [x] **Shimeji mapping:** `shime1…46` → pose table from `actions.xml`
      (`src/shimeji.ts`)

### 1.5 Basic menu bar
- [x] `menubar.rs`: tray icon with **Pause wandering**, **Character ▸**,
      **Quit** (⌘Q); template icon generated by `npm run art:shiba`
  - [x] **Pause wandering** = `behavior::hold_still` (stand/hang/ceiling-hang;
        landings finish first; gravity, grab and throw still work)
  - [x] **Character ▸** lists the bundled characters (`characters.rs`); picking
        one saves it and emits `pet://character`, which swaps the sprite
- [x] Minimal `settings.rs` (load/save JSON, defaults from §9.1): `character`
      and `wander` for now; corrupt/missing file → defaults, atomic save

### 2.1 Process and environment
- [x] `platform/macos/env.rs`: login-shell PATH (5s timeout + fallback), tested
- [x] `platform/macos/process.rs` + `stop.rs`: process group, SIGINT→SIGTERM→
      SIGKILL escalation, tested with a fake target and real process groups
      (`ProcessCtl` now signals by group id)

### 2.2 Claude runner
- [x] `claude_runner.rs`: pure `build_args(...)` + tests (permission tool
      always present; `--bare`/`bypassPermissions`/`--dangerously-skip-permissions`
      never appear; `--strict-mcp-config` always)
- [x] locate `claude`, stdin prompt
- [x] one run at a time, `cancel()`, preflight `claude auth status`
- [x] `stream_parser.rs`: `parse_line` (returns a list), tested against the
      recorded real runs
- [x] `activity.rs`: `describe(tool, input)` tested against §8.2 + path

### 2.3 Approvals
- [x] `perm_server.rs`: streamable HTTP on `axum`, 127.0.0.1, random port,
      bearer token (+ `Origin`/`Host` checks); token → OK, no token → 401.
      **Hand-rolled MCP instead of `rmcp`** (3.x API unverified; the protocol
      surface is four JSON-RPC methods). Verified against the real `claude`.
- [x] `perm_broker.rs`: oneshot map, 5-min auto-deny, deny on cancel/quit;
      tested (allow, deny, timeout, cancel)
- [x] Refuse to run prompts if the MCP server can't start: a run needs an
      `mcp_config`, which only a started `PermServer` produces, so there is no
      way to run without approvals; the user-facing message comes in 2.4
- [x] Opt-in end-to-end tests with the real `claude`
      (`cargo test -- --ignored real_claude`): allow → file written,
      deny → no file

- [x] `activity.ts`: label above the pet (drawn over the sprite's headroom: the
